## 题目描述
输入
第一行输入t，表示有t个测试实例
第二行输入顶点数n和n个顶点信息
第三行起，每行输入邻接矩阵的一行，以此类推输入n行

第i个结点与其它结点如果相连则为距离，无连接则为0，数据之间用空格隔开。

第四行输入一个顶点v，表示求该顶点v到其他顶点的最短路径距离

以此类推输入下一个示例


输出

对每组测试数据，输出：

每行输出顶点v到某个顶点的最短距离和最短路径

每行格式：顶点v编号-其他顶点编号-最短路径值----[最短路径]。没有路径输出：顶点v编号-其他顶点编号--1。具体请参考示范数据

## 重点
1. 与prim类似，但要记录整条路径与长度
2. 记录完整路径方法：先加入第一个顶点，再依次加入走过的路径本身
3. 用邻接表会好一点

## Dijkstral算法主体
注意一开始到所有点路径都为无穷，
1. 初始化问题：每次用的边集都是一个，因此要清空，见注释
2. 解决输出错位：若每次加入下一个点则会没有机会加入自己（可以在最后统一加入，但是一点不优雅），因而前移一单位，详见代码及注释
```cpp
//算法主体
void Dijkstra(AMGraph& G,vector<Re>&re,string D0)
{
	//初始化结果数组，下标对应序号
	re.assign(G.vnum, { {},MAXINT,false });

	//元素是否已加入，以下标表示
	vector<bool>exting(G.vnum, false);

	//获取目标顶点下标
	int loc0=Local(G, D0);
	if (loc0 < 0)return;
	re[loc0].finished = true;
	//问题：将首元素加入，后续改为加入自己而非前驱
	re[loc0].critical .push_back( D0);

	exting[loc0] = true;
	int nowone = loc0;
	//一共有n-1个结果
	for (int i = 1; i < G.vnum; i++)
	{
		//对新点的每一条
		for (int j = 0; j < G.vnum; j++)
		{
			// 边 判断是否更新
			if(G.arcs[nowone][j])
			{
				int newsum = G.arcs[nowone][j] ;
				if (re[nowone].sum != MAXINT)
					newsum += re[nowone].sum;
				if (newsum < re[j].sum)
				{
					re[j].sum = newsum;
					//每次用的都是同一套东西，需要及时清理残余数据，因此无条件赋值
					//if(!re[nowone].critical.empty()) 
						re[j].critical = re[nowone].critical;
					re[j].critical.push_back(G.vexs[j]);
					//加入自己
					//re[j].critical.push_back(G.vexs[nowone]);

				}
			}

			
		}
		//找到最小的边，固定其结局
		int minone = loc0;
		int min = MAXINT;
		for (int i = 0; i < re.size(); i++)
		{
			if (re[i].sum < min && !re[i].finished)
			{
				min = re[i].sum;
				minone = i;
			}
		}
		re[minone].finished = true;
		nowone = minone;

	}
}
```
