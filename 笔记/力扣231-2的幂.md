本题有多种解法

## 1.普通解法
将所给数除2，若出现余数不为0说明不是2的幂  
重点掌握代码逻辑，排列  
```cpp
//普通
bool test01(int n, int flag)
{
	//边界：非正整数都不是
	if (n <= 0)return false;
	
	//设置余数，若余数为1则不是
	int k = 0;
	while (n!=1&&k!=1)
	{
		k = n % 2;
		n /= 2;
	}
	return !k;
}
```
## 2.位运算
2的幂有一个共同点：只有一个1，剩余全是0，要是能验证它这件事即可  
方法：  
1. 只有一个1也是最后一个1，可以将其反转，验证剩余是否全是0，反转方法：n&（n-1），由于对0也有效，故范围限定在正整数  
2. n&（-n），负数用补码，这个式子可以保留最后一个1，其余前面全置0，若是相等原来就是了
重点掌握位运算技巧
3. 位运算优先级比比较运算符低，要加括号

```cpp
//位运算
bool test01(int n, char flag)
{
	if (n <= 0)return false;
	return (n & (n - 1)) == 0;

	//第二种位运算方法
	return (n & (-n)) == n;
}
```
## 3.函数
log函数：cmath中，用log2函数，  
判断整型：n==（int）n  
就这两点
```cpp
bool test01(int n)
{
	if (n < 1)return false;
	return log2(n) == (int)log2(n);
}
```
