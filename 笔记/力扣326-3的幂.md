判断一个数是不是3的幂  
有两种方法，相对2的幂少了位运算，毕竟不是二进制的  
法一 普通方法  
重点在结构优化，将相同情况合并
```cpp
bool isPowerOfThree(int n) 
{
    if (n <= 0)return false;
	int k = 0;
	while (n && n%3==0)
	{
		n /= 3;
	}
	return n==1;
}
```
法二 函数  
fabs：浮点数绝对值  
log(n)/log(m)：以m为底n的对数->lognm  
round：四舍五入的值，可以用于判断是否是整型  
```cpp
bool isPowerOfThree(int n,int flag)
```
