## 题目
输入
第一行两个整数 n m，表示顶点数（事件）和边数（活动），顶点编号 1 ~ n。

接下来 m 行，每行三个整数 u v w，表示活动从事件 u 到事件 v，持续时间为 w。

```text
6 8
1 2 3
1 3 2
2 4 2
2 5 3
3 4 4
3 6 3
4 6 2
5 6 1
```

输出
第一行：整个工程的最短完成时间。

第二行：关键路径上经过的事件序列（若有多条，输出任意一条）。

第三行：所有关键活动（按 u->v 输出，多个用空格分隔）。

```text
9
1->3->4->6
1->3 3->4 4->6
```

## 图定义
仍然是边集数组加索引表，不用看，只需注意输入从1开始，索引都改成0开始
```cpp
struct Edge
{
	int u, v, w;
};
struct ALGraph
{
	//存放对应位置是s中的第几条边
	vector<vector<int>> e;
	//边集数组
	vector<Edge>s;

	int vnum,anum;
};

void CreateALGraph(ALGraph& G)
{
	//Edge a;
	cin >> G.vnum>>G.anum ;
	G.e.resize(G.vnum);
	G.s.resize(G.anum);
	for (int i = 0; i < G.anum; i++)
	{
		int u, v;
		cin >> u >> v>>G.s[i].w;
		G.s[i].u = u - 1;
		G.s[i].v = v - 1;
		G.e[G.s[i].u].push_back(i);
		
	}
	
}
```

## 关键路径主函数
1. 源点不一定是第一个，不一定只有一个-->解决，入度为0的都是源点
2. 汇点不一定只有一个-->解决，索引表为空的都为汇点，G.e[0]为空证明出度边
3. 汇点初始化不能是最长时间-->因为汇点可以有多个，并且不会更新，所以要让汇点初始化为自己的值才对
4. 注意拓扑中用//**//标记的位置遍历for循环的迭代器的含义
5. 打印时先排序，因为如果关键路径有多条会乱
6. 拓扑数组应用时要加topo[i]，一定看一下有这个的地方，i是普通序号，topo[i]是在拓扑数组中存放的序号
```cpp
void Critical_Path(const ALGraph& G)
{
	//关键路径要有4个数组，但后续3个都可以由ve而来，因此需要时再定义
	vector<int>ve(G.vnum, 0);
	//拓补排序需要入度数组
	vector<int>in_deg(G.vnum,0);
	for (const auto& i : G.s)
	{
		in_deg[i.v]++;
	}

	//拓补排序
	queue<int>q;
	vector<int>topo;
	//从第一个元素开始
	for(int i=0;i<in_deg.size();i++)
		if(in_deg[i] == 0)q.push(i);

	while (!q.empty())
	{
		int top = q.front();
		q.pop();
		topo.push_back(top);

		//**//i遍历e[top]，代表在s中的索引，即第几条边
		for (auto& i : G.e[top])
		{
			int nextout = G.s[i].v;
			in_deg[nextout]--;
			if (in_deg[nextout] == 0)
				q.push(nextout);

			//结点原本数据与新路径相比
			ve[nextout] = max(ve[top] + G.s[i].w, ve[nextout]);

		}
	}

	//拓扑失败，证明有环
	if (topo.size() != G.vnum)return;
	//用最大值初始化事件最晚开始数组
	int T=*max_element(ve.begin(),ve.end());
	vector<int>vl(G.vnum, T);
	//多汇点情况，汇点不会更新，需设置为自己的值而非最大值
	for (int i=0;i<vl.size();i++)
	{
		if (G.e[i].size() == 0)vl[i] = ve[i];
	}
	//逆拓补
	
	//如果是汇点则遍历立即结束无影响
	for (int i = topo.size()-1; i >= 0; i--)
	{
		//找到所有边中最小的
		for(const auto&j:G.e[topo[i]])
		{
			//找到边
      //**//j代表该边是第几条边
			Edge edge = G.s[j];
			vl[topo[i]] = min(vl[topo[i]], vl [edge.v]- edge.w);
		}
	}

	//线代表活动，可以在循环中计算，并不需要记录
	//vector<int>e;
	//vector<int>l;

	vector<Edge>CriticalAct;

	//按照拓扑序，对每条线初始化
	for (int i = 0; i < topo.size(); i++)
	{
		//找到序号对应的所有线，进行初始化
		for (const auto&j:G.e[topo[i]])
		{
			int enode = ve[topo[i]];
			int lnode = vl[G.s[j].v] - G.s[j].w;
			//e.push_back(enode);
			//l.push_back(lnode);
			if (enode - lnode == 0)CriticalAct.push_back(Edge{ topo[i],G.s[j].v,G.s[j].w });
		}
	}
	print(CriticalAct);
}
```
