# P5318 【深基18.例3】查找文献

## 题目描述

小 K 喜欢翻看洛谷博客获取知识。每篇文章可能会有若干个（也有可能没有）参考文献的链接指向别的博客文章。小 K 求知欲旺盛，如果他看了某篇文章，那么他一定会去看这篇文章的参考文献（如果他之前已经看过这篇参考文献的话就不用再看它了）。

假设洛谷博客里面一共有 $n(1\le n\le10^5)$ 篇文章（编号为 $1$ 到 $n$）以及 $m(1\le m\le10^6)$ 条参考文献引用关系。目前小 K 已经打开了编号为 1 的一篇文章，请帮助小 K 设计一种方法，使小 K 可以不重复、不遗漏的看完所有他能看到的文章。

这边是已经整理好的参考文献关系图，其中，文献 $X\to Y$ 表示文章 $X$ 有参考文献 $Y$。不保证编号为 $1$ 的文章没有被其他文章引用。

![](https://cdn.luogu.com.cn/upload/image_hosting/f4n4tlhi.png)

请对这个图分别进行 DFS 和 BFS，并输出遍历结果。如果有很多篇文章可以参阅，请先看编号较小的那篇（因此你可能需要先排序）。

## 输入格式

共 $m+1$ 行，第 $1$ 行为 $2$ 个数，$n$ 和 $m$，分别表示一共有 $n(1\le n\le10^5)$ 篇文章（编号为 $1$ 到 $n$）以及 $m(1\le m\le10^6)$ 条参考文献引用关系。

接下来 $m$ 行，每行有两个整数 $X,Y$ 表示文章 $X$ 有参考文献 $Y$。

## 输出格式

共 $2$ 行。

第一行为 DFS 遍历结果，第二行为 BFS 遍历结果。

## 本质
DFS和BFS，可能要排序

## 重点
1. 邻接表还是邻接矩阵：邻接矩阵为10^5*10^5，过大，使用邻接表
2. BFS标记visit位置：一入队就标记，防止重复入队
3. 邻接表尾插法：设立尾指针，并且，更新-->链表初始化出现问题
4. 邻接表如何排序：先收集再排序再初始化表
5. 看优化部分

## 优化
使用vector代替普通邻接表，起到类似邻接矩阵的作用

## 优化部分
理解边集数组+索引表的定义，初始化，用法
### 定义（预备工作）

{
	int u, v;

//边集数组
vector<Edge>s;

//e的下标位置为边头，存放边尾，当二维数组用

### 初始化
e为什么存放的是第几条边：可以有边的全部信息，否则只是有边头边尾两个信息
```cpp
void CreateALGraph()
{
	cin >> vexnum >> arcnum;

	//初始化边集数组
	for (int i = 0; i < arcnum; i++)
	{
		int loc1, loc2;
		cin >> loc1 >> loc2;
		s.push_back(Edge{ loc1, loc2 });
	}
	sort(s.begin(), s.end(), cmp);

	//e的第一维表示第几条边的边头，第二维表示存放的是对应s中的第几条边
	for (int i = 0; i < arcnum; i++)
	{
		e[s[i].u].push_back(i);
	}
}
```

### DFS
e存放第几条边，因而在s中索引
```cpp
void DFS(int No)
{
	cout << No + 1 << " ";
	visit[No] = true;
	
	//遍历No所在的行
	for (int i = 0; i < e[No].size(); i++)
	{
		int point = s[e[No][i]].v;
		if (!visit[point])
		{
			DFS(point);
		}
	}
		
}
```
## 邻接表定义
其中visit数组可以写在函数内，详见笔记BFS，DFS部分
```cpp
struct ArcNode
{
	int adjvex;
	ArcNode* next;
};
struct VexNode
{
	ArcNode* first;

	//设立尾指针
	ArcNode* r;
};
struct ALGraph
{
	vector<VexNode>vexs;
	int vexnum, arcnum;
	vector<bool>visit;
};
```
## 初始化邻接表
注意更新尾指针
```cpp
struct Edge
{
	int u, v;
};
bool cmp(const Edge& e1,const Edge& e2)
{
	return e1.u == e2.u ? e1.v < e2.v: e1.u < e2.u;
}
void CreateALGraph(ALGraph&G)
{
	int v,a;
	cin >> v>>a;
	G.vexnum = v;
	//初始化vector数组，别忘
	G.vexs.assign(G.vexnum, VexNode{NULL,NULL});
	
	G.arcnum = a;

	//先收集
	vector<Edge>Earr;
	Earr.assign(G.arcnum, { 0,0 });
	for (int i = 0; i < G.arcnum; i++)
	{
		cin >> Earr[i].u >> Earr[i].v;
	}
	sort(Earr.begin(), Earr.end(),cmp);
	//初始化
	for (int i = 0; i < G.arcnum; i++)
	{
		int loc1 = Earr[i].u;
		int loc2 = Earr[i].v;
		//初始化一个边界点，尾插法加入
		ArcNode* newnode = new ArcNode;
		
		newnode->adjvex = loc2-1;

		newnode->next = NULL;

		if (G.vexs[loc1-1].first == NULL)
			G.vexs[loc1-1].first = newnode;
		
		//先确定存在才能访问
		if (G.vexs[loc1 - 1].r != NULL)
		{
			G.vexs[loc1 - 1].r->next = newnode;
		}
		//更新尾指针
		 G.vexs[loc1 - 1].r = newnode;
	}
	
}
```

## BFS
标记visit时机
```cpp
void BFS(ALGraph& G)
{
	queue<int>que;
	que.push(0);
	G.visit[0] = true;
	while(!que.empty())
	{
		int top = que.front();
		que.pop();
		cout << top + 1 << " ";
		ArcNode* p = G.vexs[top].first;
		while (p)
		{
			if (!G.visit[p->adjvex])
			{
				que.push(p->adjvex);
				G.visit[p->adjvex] = true;
			}
			p = p->next;
		}
		
	}
}
```
DFS类似，记得恢复visit数组
